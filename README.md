# E-Commerce Sales Analysis Dashboard

## Overview

This project analyzes e-commerce sales data to identify revenue trends, product performance, category performance, and valuable customers.

The project combines data analysis with an Excel dashboard to present important business insights in an easy-to-understand visual format.

## Dashboard

![E-Commerce Sales Dashboard](dashboard_preview.png)

## Key Metrics

- Total Revenue: ₹75,067
- Total Orders: 14
- Units Sold: 34
- Top Category: Furniture

## Analysis Performed

- Monthly revenue analysis
- Revenue analysis by product category
- Top-selling/product revenue analysis
- Customer spending analysis
- Identification of top-performing categories and customers

## Dashboard Features

The Excel dashboard contains:

- KPI cards for Revenue, Orders, Units Sold and Top Category
- Monthly Revenue Trend
- Revenue by Category
- Top Products by Revenue
- Top Customers by Revenue

## Tools Used

- SQL
- Microsoft Excel
- CSV
- Data Analysis
- Data Visualization

## Project Structure

- `Ecommerce_Sales_Dashboard.xlsx` - Final Excel dashboard
- `dashboard_preview.png` - Dashboard preview
- `Data/` - Analysis output datasets
- SQL/analysis files - Queries used for sales analysis

## Business Insights

- Furniture generated the highest category revenue.
- Revenue showed an overall upward trend despite fluctuations between months.
- A small number of high-performing products contributed significantly to overall revenue.
- Customer analysis helps identify high-value customers based on their total spending.

## Purpose

This project demonstrates practical skills in SQL, data analysis, Excel dashboard creation, data visualization, and extracting business insights from sales data.
